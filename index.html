Observações e próximos passos

Como funciona

O radar compara, quando existem pelo menos seis avaliações, a média das três mais recentes com a média das três anteriores. Uma diferença de 1 valor ou mais sinaliza subida ou queda. Médias abaixo de 5 sugerem prioridade de apoio. Com menos avaliações, o sistema assinala que ainda não há dados suficientes para avaliar uma tendência.

Grupos automáticos de apoio

O sistema agrupa alunos por necessidade de apoio e acompanha a evolução. A evolução compara a média anterior com a média actual; subidas aumentam o índice do grupo e descidas reduzem-no.

💾 Backup e recuperação

Os dados continuam guardados localmente neste dispositivo. Faz uma cópia antes de mudar de telemóvel ou importar informação.

Aponta a câmara para o QR de backup. A permissão da câmara é necessária e o site deve estar em HTTPS.

🌐 Sincronização online entre dois dispositivos

Depois de configurar um projeto Firebase, os dois dispositivos podem iniciar sessão com a mesma conta e sincronizar turmas, alunos, notas e grupos. As credenciais de configuração ficam guardadas localmente; a palavra-passe não é guardada.

Estado: sincronização online não configurada.

Configuração necessária uma única vez por dispositivo. No Firebase Console, ativa Authentication → Email/Password e cria uma Realtime Database. Usa as regras de segurança indicadas no guia incluído no pacote.

Importante: quando a sincronização está ligada, as alterações recebidas da nuvem atualizam os dados locais. Para evitar conflitos, não edites os mesmos registos simultaneamente nos dois dispositivos; faz backup antes de começar.

Apagar dados

Esta operação apaga os dados locais. Descarrega um backup primeiro se quiseres conservá-los.
